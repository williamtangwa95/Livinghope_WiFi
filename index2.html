How to get connected

Simple steps for new customers

⌁

1. Join the Wi-Fi network

Open Wi-Fi settings on your phone and select the advertised network name. The exact SSID should be confirmed by the operator before launch.

▤

2. Buy a voucher

Choose a package above and purchase a valid voucher from the authorised attendant. Ask for the correct package and keep the code private.

✓

3. Sign in

Open the Wi-Fi sign-in page that appears, enter the voucher credentials as instructed, and connect. If the page does not appear, open a browser and visit a non-HTTPS website.

Need help connecting?

Contact the local Wi-Fi attendant for voucher purchase, login assistance or package questions.
Operator contact: Add the confirmed phone number and support hours before publishing.
